# External Online Resources

This is a listing of the very best external online resources that the exec and members have found and shared over the years. Take a look through if you are looking for inspiration. There is an awful lot here!

## Tutorials

- See some C# and shader tutorials for the Unity game engine at [Catlike Coding](https://catlikecoding.com/unity/tutorials/). Noise, procedural mesh generation, water and the unity rendering pipeline are all taught on this highly detailed site.

- [Minions Art](https://www.patreon.com/cw/minionsart) has some great tutorials on shader graphs for sky-boxes, lava and laser visual effects.

{% include image.html
    src="/wgd-assets/lfs/third-party-snippets/roystantoon.png"
    style="float: right; width: 50%; margin: 0px 0px 0px 1em;"

- Alan Zucconi has a very large catalogue of [tutorials](https://www.alanzucconi.com/tutorials/), including orbital mechanics, plugin development for Minecraft, and 4D rendering.

- Roystan has fewer but equally substantive [tutorials](https://roystan.net/articles/) which discuss grass, outline and toon shaders.

- See some career advice alongside shader and procedural geometry tutorials on [Linden Reid](https://lindenreidblog.com/all-tutorials/)'s blog.

- A collection of detailed Unity [tutorials](https://unity.stelabouras.com/) - everything from the marching cubes algorithm to wave function collapse.

- A short but instructive [video](https://www.reddit.com/r/Unity3D/comments/fqabkx/i_tried_to_explain_procedural_animation_in_10/) on procedural animation in ten steps.

- [Tutorials](https://lazyfoo.net/tutorials/SDL/) on lower level game programming design with C++ in SDL.

- Find some interesting tutorials on shaders and custom rendering by [Ameye](https://ameye.dev/).

- See [this](https://www.youtube.com/watch?v=LOhfqjmasi0) Godot tutorial from the renown developer, [Brackeys](https://www.youtube.com/@Brackeys).

## Assets

{% include image.html
    src="/wgd-assets/lfs/third-party-snippets/kenny-assets-sample.png"
    style="float: right; width: 50%; margin: 0px 0px 0px 1em;"
    caption="An exemplar sample of Kenny's assets"
    link="https://kenney.nl/"
%}

- [Game Programming Patterns](https://gameprogrammingpatterns.com/) is a great (paid) resource for understanding structures and systems in making games.

- The [Unity student plan](https://unity.com/products/unity-student) provides access to the Unity Pro Editor & Cloud Ecosystem.

- [Kenny's Assets](https://kenney.nl/assets) is an asset library that is vast, various and virtuosic in quality (and hugely popular, for good reason).

- Find lots of free art at [OpenGameArt](https://opengameart.org/).

- A paid Unity vector graphics [library](https://acegikmo.com/shapes/) by Freya Holmér.

- The [Unbound](https://www.unbound.io/about) game engine: a fascinating program built to support SDF Sculpting.

- The [Level Designer Toolkit](https://ldtk.io/) is an open source app for 2D design prototyping.

- A large (and completely free) library of 3D art assets by [Quaternius](https://quaternius.com/).

## Stories and narratives

- Brandon Sanderson's BYU [lecture series](https://www.youtube.com/playlist?list=PLSH_xM-KC3Zv-79sVZTTj-YA6IAqh8qeQ) on writing is a useful resource for the story game inclined.

- A [course](https://www.gregbuchanan.co.uk/courses) by Greg Buchanan on writing a narrative game.

## Miscellaneous

- A [twitter thread](https://x.com/MaddyThorson/status/1238338574220546049) from a [Celeste](https://store.steampowered.com/app/504230/Celeste/) developer about platformer tips & tricks.

- An 'awesome repo' (curated list) for learning game design, [awesome-learn-gamedev](https://github.com/dawdle-deer/awesome-learn-gamedev).

- Among many other excellent tutorials by [Game Maker's Toolkit](https://www.youtube.com/@GMTK), [The Two Types of Random](https://www.youtube.com/watch?v=dwI5b-wRLic) provides some good insight into RNG in games.

- A free [VR game](https://store.steampowered.com/app/533970/Blocks_by_Google/) about 3D modelling.

- [Handmade Cities](https://www.youtube.com/channel/UCkiOutDcOG0KRLQc71Pd-Fg) host indie conferences for low-level programmers.
